# Original synthetic decoder fixtures (not game resources)

These tiny DDS, SLD and DAT files are generated entirely by this project's
scripts/make-asset-fixtures.py using original colored blocks and constructed
metadata. They contain no Microsoft, Forgotten Empires or third-party mod art.
They are distributed under this repository's GPL-3.0-only license.

Choose this folder in the local desktop “本地素材” picker to exercise the full
read-only pipeline without installing a game. Read the DAT, choose Synthetic
Civilization, select unit #109 in the sample map, resolve its mapping and preview
fixture_acorn_marker.sld. This is a deliberately artificial survey marker.
The checkerboard DDS can be manually assigned to the active terrain type.

This establishes software behavior on constructed files. It is not evidence
of compatibility with actual AoE2 DE installed assets or game-exact rendering.
